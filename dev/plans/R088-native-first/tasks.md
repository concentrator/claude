# R088 tasks - Native first

Why: rules that override Claude Code's defaults cost turns, dispatches and tokens a native feature would save.

## Open

- The Stop hook blocks the turn end and every prompt from a high context fill carries a hand-off warning, against native compaction.
- The runner ledger takes one entry per event, recording what the transcript, git and the task report already hold.
- A question, a review fix or a docs mismatch gets a fresh seat and a revert where continuing the same agent would do.
- The permission pre-flight maintains a Bash rule set that auto mode ignores, and under a human supervisor refuses prompts the user could answer.
- The auto-mode classifier is not configured, though an `autoMode` block in the user settings would carry the environment and the never-list.
- The code reviewer duplicates the bundled `/code-review` and forbids calling it.
- A change can be reviewed at branch close, at batch close and again at release.
- The full test tier runs locally right before CI runs it.
- The model quota script reads the OAuth token to pre-check capacity the reactive fallback already handles.
- CI is polled to green where a background `gh pr checks --watch` or Monitor would notify.
- The session may not write plan text, so a planner seat re-derives context the session holds, where plan mode would do.
- A small change can need a shape, a detail and a code MR/PR.
- Each docs claim is written in the plan and again in the report and checked by three seats.
- The run loop is prose the runner interprets each time, where a saved workflow would carry the sequence and the loop bound in code.
- A section cite loads its whole file, so each seat dispatch reads thousands of words beyond its step.
- The size caps exempt the companions, which grew into the largest files the seats read.
- Every seat cites the duty table only to learn that none of it is its own.
- The writing-artifacts rule loads on any Markdown read in any project, though most of it binds DEV artifacts only.
- Questions reach the user as free text where `AskUserQuestion` would offer the choices.
